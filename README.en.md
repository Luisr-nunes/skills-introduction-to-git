Completed exercise from GitHub Skills' [Introduction to Git](https://github.com/skills/introduction-to-git) course, covering the fundamentals of version control with Git.

## Completed steps

1. Introduction to Git version control
2. Creating your first repository
3. Exploring Git history
4. Comparing changes
5. Working with branches
6. Introduction to collaboration

Each step was validated automatically by a GitHub Actions workflow (`.github/workflows`), and the instructions are in `.github/steps`.

## Project used in the exercise

`src/` contains **Stack Overflown**, a programming-themed puzzle game in HTML, CSS and JavaScript, used as the base to practice commits, diffs and branches.

To play, open `src/index.html` in a browser.
